## 📌 Sobre o Projeto

Este repositório é dedicado ao aprendizado prático de processos **ETL (Extract, Transform, Load)** utilizando Python e a biblioteca Pandas.

O objetivo é explorar as principais etapas de um pipeline de dados, desde a extração de informações de diferentes fontes até sua transformação, limpeza, organização e posterior carregamento.

Por meio de exemplos práticos e notebooks Jupyter, o projeto aborda diferentes formatos de arquivos e fontes de dados, simulando processos comuns encontrados em rotinas de Engenharia e Análise de Dados.

## 🎯 Objetivos

- Compreender os fundamentos do processo ETL.
- Desenvolver pipelines de dados utilizando Python.
- Praticar a extração de dados de diferentes fontes.
- Aplicar técnicas de limpeza, transformação e organização de dados.
- Trabalhar com diferentes formatos de arquivos.
- Desenvolver familiaridade com fluxos de processamento de dados.

## ⚙️ Processo ETL

O projeto explora as três principais etapas de um pipeline ETL:

### 1. Extract — Extração

Coleta de dados provenientes de diferentes fontes, incluindo:

- Arquivos CSV.
- Planilhas Excel.
- Arquivos JSON.
- APIs públicas.

### 2. Transform — Transformação

Aplicação de técnicas para preparar os dados para utilização:

- Tratamento de valores ausentes (*missing values*).
- Remoção de duplicatas.
- Padronização de informações.
- Conversão de tipos de dados.
- Filtragem e seleção de registros.
- Manipulação e reorganização de DataFrames.

### 3. Load — Carregamento

Armazenamento dos dados processados em formatos estruturados, permitindo sua reutilização em análises, relatórios e outros processos.
